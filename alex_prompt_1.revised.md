Named pitfalls to avoid, each of which must be addressed rather than assumed. (i) Index confusion: silently swapping [L : Q] and [P : L]; every index statement must name which one, and any use of [P : Q] = [P : L][L : Q] must be justified. (ii) Direction confusion in Q1: assuming the correspondence between quotients of SL_n(C) and intermediate lattices is inclusion-preserving rather than inclusion-reversing (or vice versa) without checking on the extreme cases L = Q and L = P. (iii) Assuming without proof that every intermediate lattice has the form Q + Z v for a single v in P. (iv) Assuming the number of intermediate lattices of index d equals 1 merely because the number of divisors of |P/Q| matches the number of lattices found, without determining the group structure of P/Q. (v) Conflating an element of P with its class in P/Q; expressions like 'alpha_1, omega_2, omega_3' must be turned into a subgroup of P before any claim is made about them. (vi) Convention drift: switching between A and its transpose, or renumbering alpha_1, alpha_2, alpha_3 mid-argument, which matters because Q5 names specific indices. (vii) Ignoring the degenerate case n = 2, where there is a single simple root alpha_1, and the case where d = |P/Q|.
